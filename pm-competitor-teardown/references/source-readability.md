# 来源可读性分级与获取方式

## 分级

| 等级 | 含义 | 处理方式 |
|---|---|---|
| A 直接可读 | 无需登录，正文/价格/文档可直接抓取 | 用 fetch_sources.py 抓取正文 |
| B 需登录或验证码 | 需账号、地区账号或有反爬（如部分应用商店评论区） | 用户手动导出/截图，粘贴文本 |
| C 需付费或工具账号 | 数据平台（七麦、点点、蝉妈妈、SimilarWeb 等） | 用户购买或提供截图/导出文件，标注口径 |
| D 无法获取 | 后台数据、非公开接口 | 标"未获取"，禁止编造；必要时用公开信息构造区间估计并标 C 级 |

## 常见来源的获取方式

| 来源 | 典型等级 | 说明 |
|---|---|---|
| 竞品官网、定价页、帮助中心、开发者文档、Changelog | A | 一般可直接抓取，注意地区差异与页面语言 |
| 公司财报、招股书、投资者关系 PDF | A | 用 PDF 原文，注意统计口径与时间 |
| 应用商店商品页（App Store / Google Play） | A/B | 商品页通常可读；评论区常需登录或分地区账号，建议手动导出 |
| G2 / Capterra / Trustpilot | B | 常需登录或有人机验证，截图或复制原文 |
| Reddit | A/B | 可用 old.reddit.com 或 .json 接口；被墙时手动粘贴 |
| X（Twitter） | B | 多数内容需登录，手动截图 |
| 国内数据平台（七麦、点点、蝉妈妈、新抖、飞瓜、AppGrowing） | C | 多为付费或登录，导出截图并注明口径 |
| SimilarWeb / Sensor Tower / data.ai | C | 付费墙，公开页面只能看部分数据 |
| 黑猫投诉、商家社区、小红书、知乎、微博、贴吧 | B/C | 多需登录或反爬，建议手动复制原文与截图 |
| 广告库（Google Ads Transparency、Meta Ad Library） | A/B | 可能受地区或登录限制，记录查询条件与日期 |

## 用户需要提供什么

- URL 清单（每行一个，可加注释说明该来源用来回答什么问题）；
- 无法抓取时：正文文本、评论区截图、数据平台导出 CSV/截图；
- 每条材料的抓取/截图日期与地区口径。
