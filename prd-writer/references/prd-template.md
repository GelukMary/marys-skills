# PRD 模板

## 0. 变更记录
- 版本｜日期｜修订人｜变更摘要

## 1. 背景与问题
- 现状（附证据：数据/用户反馈/竞品）
- 为什么现在做、不做的代价

## 2. 目标与成功指标
- 业务目标一句话
- 主指标：定义 + 基线 + 目标值
- 护栏指标：防止以伤害 A 换 B

## 3. 范围与用户场景
- 本期做 / 不做
- 核心用户场景（谁、在什么情况、做什么）

## 4. 需求详述
- 功能点：每条含触发条件、交互、默认值、异常态
- 数值规则：公式 + 逐级数表，不用模糊词

## 5. 指标与埋点对账
- 指标 → 埋点事件 → 上报字段 → 使用决策

## 6. 异常与边界
- 数据缺失、并发、权限、兼容、灰度回滚

## 7. 待定项
- 🔵 问题｜影响 | 需要谁拍板 | 截止时间

## 8. 评审记录
- 评审结论、遗留问题回填、版本变化
