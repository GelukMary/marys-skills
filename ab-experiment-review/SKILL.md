# AB Experiment Review · 实验复盘

来自一次真实默认套餐实验：埋点能分组、金额表没有组别，用 SKU 均价还原组销售额。

## 先读这个

1. **先问口径**。相对提升还是百分点？基线是实验前还是对照组？分母是谁？
2. **会话价值 = 该组净销售额 ÷ 该组订阅页展示次数**。两组展示量不同，比率才可比。
3. **主指标 + 护栏指标一起看**。统计显著不等于业务显著。
4. **不确定就写不确定**，不替业务下因果结论。

## 工作流

### 1. 重建实验卡

假设、改动内容、分流方式、每组样本、实验时长、主指标、护栏指标、同期外部事件（投放/活动/合规）。

### 2. 口径审计

- 对照组和实验组的指标是否同口径、同时间窗口。
- 埋点支付成功数 与 ODS 订单数是否一致；差异超过 2% 先对齐口径。
- 金额拿不到分组时，用三步估算法：SKU 客单价（A+B 总销售额÷总订单数）→ 组销售额（客单价×组订单数）→ 会话价值（销售额÷展示次数）。
- 估算口径的已知偏差：实验组如果更多来自低价区，组内客单价会更低，估算会偏乐观。

### 3. 算指标

- 完成率 = 支付成功（埋点）÷ 订阅页展示次数。
- 会话价值、ARPPU、周单占比、每千展示收入。
- 显著性：两比例检验，α=0.05、功效 80%；样本不足时不要下结论。

```bash
python scripts/significance_check.py --control-n 10000 --control-c 450 --treatment-n 10000 --treatment-c 520
```

### 4. 判定规则

- 会话价值 ≥ 对照组 × (1−容忍度)（默认容忍度 1%）。
- 完成率、ARPPU 不下降；周单占比变化与续费回滚能力一起看。
- 全部通过 → 可以全量；主指标过、护栏不过 → 小流量继续观察；主指标不过 → 不建议全量。

### 5. 输出复盘卡片

结论可信度（/10）→ 可采信的结论 → 口径/统计问题 → 混淆因素 → 全量条件 → 补实验建议。

## 常见失败

- 只报"提升 15%"不报基线和分母。
- 用混合客单价替代组内客单价，忽略国家结构差异。
- 样本量不够就宣布显著。
- 忘记退款、取消、续费这些护栏。
- 把大盘或投放带来的变化算成实验效果。
