# 真题样例与参考拆解

以下只给拆解骨架，不背答案。

## 例 1：海外订阅工具 App 收入下滑 30%，怎么分析？

1. 先把"收入"拆开：新单收入、续费收入、退款冲减，分别算下滑贡献。
2. 按 SKU/国家/渠道看是否集中：集中在一个国家更像投放或本地化问题，分散更像产品/定价问题。
3. 时间维度：去年同期、上季度、投放动作时间点对照。
4. 找证据链：若年单续费回滚且同期广告拓量，先验证"新用户结构与老用户续费行为"是否改变。
5. 输出结论时要带"下一步验证"，而不是一次性下结论。

## 例 2：免费工具要不要做会员？价格定多少？

1. 判断"用户价值是否可分档"：只有少数高价值功能被高频使用，才有付费基础。
2. 找出需求证据：主动功能使用、导出/去水印/多端同步等"效率型需求"比"好看型需求"更愿意付费。
3. 定权益边界：免费保体验，会员解决效率；避免把免费核心功能做残。
4. 定价先给锚点：参考同类工具年费、竞品、地区购买力；用两个价位做小流量 AB，而不是拍脑袋。
5. 监控：转化率、退款、取消、免费用户留存是否受损。

## 例 3：AI 功能要不要收费、按什么收费？

1. 先算成本账：单次请求模型成本 x 预估调用量，是否会把毛利吃穿。
2. 再看增量价值：用户是否因 AI 完成原本付费动作（生成、创作、导出），还是只是"玩一下"。
3. 收费形态选项：功能付费点、订阅内权益、按次/按量；先小范围灰度验证付费意愿。
4. 如果触达高但转化低，问题可能在"价值表达"而不是"功能没用"，考虑试用次数与结果展示。
5. 决定砍与留：给一个时间窗和可证伪指标，不达标就降级或下架。
