# 商业化与分析框架速查

供陪练时按问题类型调用，不给用户贴整篇，只给当前最相关的一块。

## 1. 收入下滑/异常诊断

先拆解，再归因，最后才谈改动。

- 收入 = 付费用户数 x 人均付费（ARPU/ARPPU）
- 付费用户数变化继续拆：新单 + 续费 - 流失；按 SKU/国家/渠道/套餐看哪一项贡献了变化
- 时间对比：同比、环比、近 1/6/12 个月趋势
- 外部 vs 内部：投放（买量、素材、渠道政策）、合规/审核、竞品、淡旺季
- 判断纪律：先定位"是外部动作还是产品问题"，避免把大盘变化算成自己功劳或反过来

## 2. 订阅/会员定价

- 定价本质是在转化率与每用户价值之间找平衡：收入 = 转化用户 x 单价 - 退款/撤销成本
- 常见杠杆：月付/年付默认项、首单折扣、套餐权益分层、试用期、区域定价、支付渠道
- 护栏指标：会话价值、取消率、退款率、客诉；防止"以价换量"或"以量换价"
- 决策前先写清楚弹性假设：降价 x%，预计转化 +y%，收入净变化是多少

## 3. 买量/增长 ROI

- 漏斗：曝光 → 安装 → 激活 → 试用 → 付费 → 续费/复购
- 核心账：CAC（单用户获取成本）、ARPPU、月流失率、回本周期
- 速记：LTV ≈ ARPPU / 月流失率；回本周期 ≈ CAC / ARPPU
- 判断买量是否值得：LTV/CAC 与回本周期结合业务现金流一起看，不只盯一个数

## 4. AI 功能商业化

- 先问"AI 带来的增量价值由谁付费、愿付多少"，再问技术可行性
- 选型四维：模型定价（成本/请求）、输出效果、性能（延迟/并发）、可维护性
- 功能指标不等于业务指标：触达率提升 ≠ 收入提升；要看转化、留存、付费贡献
- 上线前定义可证伪的结论：如果转化不提升，是否砍掉或降级

## 5. 案例回答通用结构

目标与约束 → 用户与场景 → 现状拆解（数据或假设） → 最可能原因/机会 → 方案与优先级 → 指标与实验 → 风险与下一步

## 常见口径提问

- 这个数字是相对值还是百分点？
- 基线是什么：实验前、对照组、历史同期？
- 分母是什么：全量用户、功能触达用户、付费用户？
- 有没有护栏指标和外部事件记录？
